# Project StarCraft

A fully reusable super heavy launch system for Kerbal Space Program 1.12.x, by KAESA: the StarCraft ship, the Super
Massive booster and the Gigazilla catch tower. The rework of KAESA StarCraft 1.0 (internal names unchanged, so old
crafts and saves keep working).

![Globelink deploy](images/imagem%20sigma%20deploy%20globelink.png)

## Features

- **StarCraft ship:** Ship Core with 3 or 6 vacuum engines; PEZ, Tanker, Cargo and Crewed noses (the Crewed one with
  10 seats, its own IVA and a docking well for a 0.9375 m port); plugin-driven flaps
- **Super Massive booster:** 33-engine cluster with 33 / 13 / 3 modes, grid fins with catch pins
- **Gigazilla tower:** catch arms you can close from the ship, launch mount with retracting clamps
- **Payload:** PEZ rack with Globelink satellites, cargo rail and payload adapter
- Four ready-to-fly sample crafts

## Requirements

**Required:** ModuleManager, B9PartSwitch, HarmonyKSP, CryoTanks, Community Resource Pack, Breaking Ground (DLC)

**Recommended:** Waterfall, TexturesUnlimited, ASET Props + RasterPropMonitor (Crewed IVA)

**Optional:** FreeIva, Benjee10 Shared Assets (NDS docking port), HullCam VDS Continued, Community Category Kit, Firefly

## Installation

1. Delete any old `GameData/KAESA/StarCraft` folder.
2. Copy the archive's `GameData` folder into your KSP folder.
3. Optional: copy the crafts in `Ships/VAB` to `saves/<your save>/Ships/VAB/`.
